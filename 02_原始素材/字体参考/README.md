# 中文手写字体参考

## 字体

- 文件：`cjkfonts_handingwriting4.ttf`
- 字体名称：cjkFonts 手写4
- 官方介绍：https://cjkfonts.io/blog/cjkfonts_handwriting4
- 官方下载：https://cjkfonts.io/downloadfont?font_id=cjkfonts_002&v=1.00
- 授权：SIL Open Font License（官方页面说明可用于个人及商业用途）
- 支持：约 1.2 万字，包含简体中文、繁体中文、英文、数字和标点；使用前仍应核对具体字形是否收录。

## 样张

`cjkFonts手写4-中文样张.png` 用“今日特价、东北大米、山茶油、鸡蛋、苹果、会员再减5元、售完为止”等项目内容展示字体效果。

## 使用决定

该字体更接近真实中文手写，而不是普通楷体或印刷体。后续黑板价目表应使用该字体，并通过不同字号、颜色、旋转角度、行距和粉笔纹理进一步模拟现场书写。
