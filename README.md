# AI 能不能干这活

一个以真实任务为基础的 AI 能力验证与短视频内容生产项目。

## 项目简介

本项目通过可复现的实际任务，验证 AI 在日常工作中的表现边界，并将测试过程制作成短视频内容。

核心栏目：

- **《AI能不能干这活》**：验证 AI 是否能够完成一个具体任务；
- **《AI怎么干这个活》**：拆解已经验证可行的任务和操作方法。

项目坚持：真实测试、不预设结论、保留首次结果、人工复核关键事实。

## 当前选题

### 选题 001：凌乱价目表整理

测试 AI 能否从排版凌乱的价目表图片中提取并整理以下信息：

- 商品名称；
- 规格；
- 原价；
- 折扣价；
- 单位。

重点验证商品、规格、价格和单位之间的对应关系，以及 AI 对模糊、错位、重复信息的处理能力。

预期交付结果是可复制到 Excel 的结构化清单，但价格对应关系、模糊文字和异常数据仍需人工确认。

## AI 员工协作体系

项目采用 AI 员工分工协作模式，由总控员工统一调度：

```text
选题策划 → 素材设计 → AI 测试 → 脚本编剧 → 剪辑发布 → 数据复盘
```

员工文档位于 [`09_AI员工/`](09_AI员工/)：

| 员工 | 主要职责 |
|---|---|
| 总控员工 | 拆解任务、调度员工、检查交付物、维护项目状态 |
| 选题策划员工 | 明确选题价值、任务边界和验收标准 |
| 素材设计员工 | 制作测试素材并建立人工标准答案 |
| AI 测试员工 | 执行真实测试，记录首次结果和二次修正 |
| 脚本编剧员工 | 根据真实测试结果编写口播稿和分镜 |
| 剪辑发布员工 | 完成剪辑、字幕、封面和发布文案 |
| 数据复盘员工 | 记录发布数据并提出下一轮改进建议 |

## 首条样片制作流程

1. 制作自制价目表测试图片；
2. 建立人工标准答案；
3. 录制 AI 首次识别和二次修正过程；
4. 对照标准答案核验结果；
5. 根据真实测试结果调整脚本；
6. 完成配音、字幕和竖屏初剪；
7. 人工检查事实、数字、隐私、版权和音画同步；
8. 导出 MP4，准备发布文案；
9. 发布后记录数据并复盘。

## 基本原则

- 不预先伪造 AI 的错误或翻车点；
- 不把推测写成事实；
- 模糊内容必须明确标记为不确定；
- 价格、数字、专有名词和最终结论必须人工确认；
- 使用自制或已获授权的素材，避免隐私泄露；
- 每个阶段完成并确认后，再进入下一阶段。
